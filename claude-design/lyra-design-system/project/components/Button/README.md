# Button

Três pesos: primário (`vega` com `on-vega`), secundário (borda `field`), silencioso (texto `vega`). 32 px de altura; variante pequena de 26 px dentro de barras e avisos. Desabilitado em `sunken` com `ink-3`.

- O consumidor fornece: o rótulo no imperativo e, se houver, um ícone de 14 px à esquerda.
- Um primário por tela. Foco visível com `focus-ring`.
