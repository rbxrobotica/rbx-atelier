# Badge

Selo de uma ou duas palavras: plano (Pro com cadeado, Livre), verificação (Verificado, Falha na verificação), Estimativa, Recuperando, tipo de edição e fonte em mono.

- O consumidor fornece: o tom e a palavra. Ícone só em Pro, Verificado, Estimativa e Falha.
- Selo nunca carrega significado sozinho; vem sempre com a palavra. Fonte (ANP, BCB, ANTT, CEPEA) usa o tom `src`, em mono, sem caixa alta.
