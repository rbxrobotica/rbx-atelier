# ImpactTable

Tabela de impacto por viagem: item com subtexto da premissa, valor de ontem, de hoje e variação, tudo em `data` alinhado à direita. Linha de total com borda `line-strong`.

- O consumidor fornece: as linhas calculadas de forma determinística, com a premissa de cada uma.
- Variação leva sinal no número. Sem verde ou vermelho.
- Em telas estreitas a tabela rola horizontalmente dentro do próprio container.
