# Field

Campo de texto, numérico em mono, seleção, interruptor e grupo de opções. Borda `field`, 32 px, rótulo em 500 acima, ajuda em `ink-3` abaixo.

- O consumidor fornece: rótulo, valor, ajuda e, no erro, a causa e a próxima ação em `err`.
- Valores numéricos usam `ly-input--data` (Source Code Pro). O erro muda a borda para `err` e acrescenta o texto; nunca só a cor.
