# ProfileForm

Formulário de perfil da operação em três grupos: frota (cavalos, consumo, custo-hora, implemento), rota de referência (origem, destino, distância, viagens por dia, carga) e entrega (avisos). Ações Salvar perfil e Cancelar.

- O consumidor fornece: o perfil atual e a validação por campo.
- O formulário diz onde o perfil fica e para que serve, e que vale a partir da próxima edição.
