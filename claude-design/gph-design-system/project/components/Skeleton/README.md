# Skeleton

Esqueleto de carregamento no formato do cartão de anúncio.

Use enquanto os resultados carregam, no mesmo grid onde os cartões vão aparecer. Anuncia "Carregando anúncios" para leitores de tela. Com `prefers-reduced-motion`, para de pulsar.

**Props:** `variant` (`card` ou `line`), `count`, `label`.
