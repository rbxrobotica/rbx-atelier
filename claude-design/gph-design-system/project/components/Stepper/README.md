# Stepper

As etapas da publicação de anúncio, com a etapa atual escrita por extenso.

Use no fluxo de publicação e edição: Categoria, Detalhes, Fotos, Preço e contato, Revisão. A linha "Etapa 3 de 5: Fotos" vem antes da lista para leitores de tela e para o celular.

**Props:** `steps` (rótulos), `current` (índice a partir de 0).

- Etapas concluídas ganham o visto em `ink`; a atual, o quadrado em `klein`.
- Não faça: mais de 6 etapas; etapas opcionais escondidas.
