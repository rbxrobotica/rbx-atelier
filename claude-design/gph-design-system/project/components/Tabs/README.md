# Tabs

Abas com contagem para separar listas da mesma página.

Use em "Meus anúncios" (Ativos, Em revisão, Pausados, Encerrados) e no perfil do anunciante. Não use para navegar entre páginas diferentes.

**Props:** `items` (`{id, label, count?}`), `value` + `onChange` (controlado) ou `defaultValue`, `label`.

As abas usam `role="tablist"`, `role="tab"` e `aria-selected`. Em telas estreitas a faixa rola na horizontal.
