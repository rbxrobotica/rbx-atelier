# BottomNav

Navegação inferior do celular, com Anunciar no centro.

Use só abaixo de `bp-s` (640px). Cinco destinos fixos: Início, Buscar, Anunciar, Meus anúncios, Conta. O item atual recebe `aria-current="page"` e cor `klein`.

**Props:** `active`, `items` (`{id, label, icon, href, primary?}`).

Cada alvo tem pelo menos 56px de altura.
