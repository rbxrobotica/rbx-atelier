# Logotipos

Contornos reais da Atkinson Hyperlegible Next ExtraBold (nenhum texto vivo). Construção, área de proteção e usos inadequados estão na seção Brand System.

- `informat-horizontal.svg`: assinatura padrão para fundo claro (`base`, `surface`). Tintas #1B5E3B (quadro), #F7FAF8 (i), #E09A5F (via do símbolo), #111A15 (nome), #B4652A (via do nome).
- `informat-horizontal-escuro.svg`: assinatura para fundo escuro. Tintas #1B5E3B, #F7FAF8, #E09A5F, nome em #E9F2EC.
- `informat-vertical.svg`: símbolo acima do nome, para espaços quadrados. Tintas como a horizontal.
- `informat-logotipo.svg`: só o nome, fundo claro. Tintas #111A15 e #B4652A.
- `informat-logotipo-escuro.svg`: só o nome, fundo escuro. Tintas #E9F2EC e #E09A5F.
- `informat-simbolo.svg`: o quadro com o i, grade 48. Tintas #1B5E3B, #F7FAF8, #E09A5F.
- `informat-mono-tinta.svg`: uma tinta só, #111A15 (ink), com o i e a via vazados no quadro. Para carimbo, gravação, documento em preto.
- `informat-mono-branco.svg`: uma tinta só, #FFFFFF, para fundo escuro ou foto. Não aparece sobre fundo claro.
- `informat-favicon.svg`: grade 16, sem bandeira e com via sólida, para 16 e 32 px.
- `informat-app-icon.svg`: 512 px, quadro sem cantos (a plataforma recorta), figura dentro do círculo seguro de 66%.
