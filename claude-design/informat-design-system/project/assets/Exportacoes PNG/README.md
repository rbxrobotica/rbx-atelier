# Exportacoes PNG

PNG para conferência e para lugares que não aceitam SVG, gerados dos SVG com cairosvg em 1x (tamanho natural) e 4x. O SVG é sempre a fonte.

- Logotipos: `informat-*-1x.png` e `informat-*-4x.png` para as dez variações. As versões `-escuro` e `mono-branco` foram exportadas sobre fundo #0E1411 (`base` escuro) para serem visíveis; as demais têm fundo transparente.
- Padrões: `informat-trilhas-1x.png`, `informat-trilhas-4x.png`, `informat-trilhas-mascara-1x.png`, `informat-trilhas-mascara-4x.png`.
- Os ícones não têm PNG: use o SVG ou o componente `Icon`.
