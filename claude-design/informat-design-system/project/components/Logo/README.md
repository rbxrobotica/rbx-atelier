# Logo

O logotipo do Informat desenhado como contornos da Atkinson Hyperlegible Next ExtraBold, com o pingo do i trocado por uma via de placa de circuito.

## Quando usar
- `horizontal` (padrão) no topo das páginas e no rodapé; `symbol` quando o espaço é quadrado (avatar, favicon, ícone de app); `wordmark` quando o símbolo já aparece por perto.
- Para arquivos (impressão, redes, documentos), use os SVG do grupo Logotipos; este componente desenha os mesmos contornos e segue o tema pelos tokens.

## O que você fornece
- `variant`, `height` (padrão 32; mínimo 24 para a assinatura horizontal, 16 para o símbolo) e, quando um link em volta já diz "Informat, página inicial", `decorative`.
- `tone="mono"` para uma tinta só (`ink`), em carimbo, fax, gravação.

## Faça
- Respeite a área de proteção: a altura do anel da via em volta de toda a assinatura.
- Deixe o símbolo sobre `mascara` (a placa) e o nome em `ink` sobre `base` ou `surface`.

## Não faça
- Não escreva "Informat" em texto vivo no lugar do logotipo.
- Não recolora a via, não gire, não aplique sombra, contorno ou gradiente.
- Não coloque o selo da RBX ao lado: a assinatura "um produto RBX" vai no rodapé, em texto.
