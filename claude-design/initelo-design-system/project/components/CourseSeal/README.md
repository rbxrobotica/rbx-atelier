Selo de curso — a "etiqueta de caderno" que identifica cada formação com número, cor e padrão.

    <CourseSeal number="01" title="Finanças pessoais com IA" curso="financas" />
    <CourseSeal variant="compacto" number="01" title="Finanças pessoais com IA" curso="financas" />

Para criar um novo curso, declare um escopo [data-curso="chave"] em components/bundle.css com --curso-cor, --curso-cor-forte, --curso-cor-suave e --curso-padrao.
