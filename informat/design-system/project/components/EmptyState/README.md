# EmptyState

Estado vazio com o pequeno desenho de trilhas e vias de cobre, um título que explica a ausência e a próxima ação.

## Quando usar
- Listas sem itens (nenhuma OS, nenhuma mensagem, nenhuma foto) e buscas sem resultado.

## O que você fornece
- `title` (o que não há), `children` (por que e o que acontece quando houver), `action` (um Button, em geral `primary`).

## Faça
- Escreva o título como fato: "Nenhuma OS aberta ainda".

## Não faça
- Não use humor nem ilustração de personagem.
- Não ponha o desenho de trilhas atrás de texto.

## Estados
Único; o desenho segue o tema (`cobre`, `field`, `surface`).
