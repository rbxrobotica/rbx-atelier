# Padroes

O padrão de trilhas com vias, a única ilustração da marca: barramento de trilhas de 3 px com dobra de 45 graus em esquadria (o espaçamento de 16 px se mantém na dobra), vias com anel de 7 px. Faixa de 960 x 120.

- `informat-trilhas.svg`: tinta única #B4652A (`cobre`), fundo transparente, para fundo claro (`base`, `surface`).
- `informat-trilhas-mascara.svg`: trilhas em #E09A5F (`cobre-via`) sobre fundo #1B5E3B (`mascara`), para faixas de marca.

Use em capa, divisória de seção, estado vazio e peças de marca. Nunca atrás de texto, nunca como textura da página inteira, nunca sob o logotipo.
