# PNG

Exportações em bitmap dos arquivos de Logos, para inspeção e para ferramentas que não aceitam SVG. Cada assinatura tem versão 1x e 4x; as versões negativas e brancas vêm sobre o fundo escuro #101114 para ficarem visíveis. O favicon tem 16, 32 e 180 px (ícone de toque) e o ícone de aplicativo, 512 px. Para produção, prefira sempre o SVG.
