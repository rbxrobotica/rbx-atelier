# Logos

Arquivos vetoriais oficiais do GPH, com as letras convertidas em contornos. Não digite o logotipo como texto.

- `gph-horizontal.svg`: assinatura principal (símbolo + GPH). Moldura `klein` #1F3AB0, ponto `ouro` #C08B2C, texto tinta #15161A. Sobre fundos claros.
- `gph-horizontal-negativo.svg`: moldura e texto brancos #FFFFFF, ponto ouro. Sobre fundos escuros ou sobre `klein`.
- `gph-horizontal-mono-tinta.svg`: tudo em tinta #15161A. Impressão de uma cor, carimbo.
- `gph-horizontal-mono-branco.svg`: tudo em branco #FFFFFF. Gravação, fundos escuros de uma cor.
- `gph-assinatura-completa.svg`: símbolo + GPH + fio + "Galeria / Premium / Hoje". Fio em `klein`. Mínimo de 160px de largura.
- `gph-assinatura-completa-negativo.svg`: versão para fundo escuro; fio em ouro.
- `gph-vertical.svg` e `gph-vertical-negativo.svg`: símbolo sobre GPH e descritor, para formatos quadrados.
- `gph-simbolo.svg`: a Moldura G sozinha (klein + ouro). `gph-simbolo-mono-tinta.svg` (tinta #15161A) e `gph-simbolo-mono-branco.svg` (branco #FFFFFF) são as versões de uma cor.
- `gph-favicon.svg`: fundo klein, G branco e ponto ouro; desenhado para 16px e 32px.
- `gph-icone-app.svg`: ícone de aplicativo 512 x 512, fundo klein, área segura de 22% em cada lado.

Área de proteção: o diâmetro do ponto em volta de toda a assinatura. Usos inadequados: veja a seção Brand System.
