# AdvertiserCard

Quem anuncia: nome, tipo, região, há quanto tempo está no GPH e quantos anúncios tem.

Use na página do anúncio (ao lado do contato) e no topo do perfil do anunciante. Mostra só fatos que o GPH registra; nada de notas, selos de qualidade ou tempo de resposta inventados.

**Props:** `name`, `type` ("Pessoa física" ou "Profissional"; ver pendência sobre `individual_type`), `memberSince`, `location`, `adsCount`, `accountConfirmed` (e-mail confirmado na conta RBX), `href` (perfil), `compact`.
