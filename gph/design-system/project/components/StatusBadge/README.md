# StatusBadge

O estado do anúncio no seu ciclo de vida, sempre com ícone e palavra.

Estados: `rascunho`, `em-revisao`, `publicado`, `pausado`, `expirado`, `vendido`, `indisponivel`, `recusado`. Use em "Meus anúncios", no topo da edição e no cartão quando o estado não for "publicado".

**Props:** `status`, `children` (troca a palavra, ex.: "Em revisão desde 09:40").

Cor nunca é o único sinal: cada estado tem palavra e ícone (ou o ponto, no caso de vendido e indisponível).
