# Logo

A assinatura horizontal do GPH desenhada ao vivo, que acompanha o tema.

Use `Logo` dentro da interface (barra de navegação, rodapé, telas de login). Para impressos e peças fora do produto, use os arquivos do grupo de assets **Logos**.

**Props:** `height` (padrão 28), `symbolOnly` (só a Moldura G, para espaços menores que 120px de largura), `label`.

No tema escuro a moldura fica em `ink` (branca) e o ponto continua em `ouro`, como a versão negativa oficial.

- Faça: respeitar a área de proteção (o diâmetro do ponto em volta de toda a assinatura).
- Não faça: recolorir a moldura, trocar a fonte do "GPH", girar ou distorcer.
