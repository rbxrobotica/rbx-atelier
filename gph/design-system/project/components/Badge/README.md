# Badge

Selo curto de uma ou duas palavras.

Use para marcar um atributo ao lado de um título: "Destaque", "Profissional", "Novo". Para o ciclo de vida do anúncio use `StatusBadge`.

**Props:** `tone` (`neutral`, `klein`, `ouro`, `ok`, `warn`, `err`, `sold`), `icon`, `dot` (o ponto vermelho), `children`.

- Faça: sempre texto; ícone ou ponto só acompanham.
- Não faça: mais de dois selos no mesmo cartão.
