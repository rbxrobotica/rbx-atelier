# Wordmark

O letreiro "GPH". Com o símbolo ao lado vira `Lockup`; sozinho é a marca na barra de navegação e em texto.

Use na barra de navegação (`size="m"`, 42px; `"s"` no celular), no rodapé e em capas (`"l"`, 120px). Sempre `magenta` com `text-glow-white` em Noite; em Dia o brilho some sozinho. Com `href`, vira link para a página inicial com `aria-label`.

**Props:** `size` (`s` | `m` | `l`), `href`, `className`.

- Nunca mude a fonte, a cor ou a inclinação. Nunca escreva "Galeria Premium Hoje" ao lado dele na navegação; o nome por extenso fica no rodapé.
- Área de proteção: a altura do "H" em volta.
