# Lockup

A assinatura completa: `Symbol` à esquerda, `Wordmark` à direita, como no logo original do grupo de WhatsApp. O símbolo mede 0,95 do corpo da letra e fica alinhado pelo centro vertical das maiúsculas; o gap é um quarto do corpo (no logo de 2017: símbolo 1,3× a altura das maiúsculas, gap de 0,35; aqui apertado um pouco para o conjunto ler como uma palavra só).

Use no rodapé, em capas, na foto de perfil e em telas de abertura. Na barra de navegação continua o `Wordmark` sozinho: a barra já tem brilho, links e botão, e a lojinha ali viraria ruído.

**Props:** `size` (`s` | `m` | `l`, mesmos corpos do Wordmark), `href`, `className`.

- O brilho fica só no wordmark; o símbolo nunca brilha.
- Nunca empilhe o símbolo em cima do wordmark, nunca mude a ordem.
- Área de proteção: a altura do "H" em volta do conjunto.
