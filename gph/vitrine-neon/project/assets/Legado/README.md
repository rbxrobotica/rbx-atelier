# Legado

Capturas do protótipo de 2023-2024 (`Galeria-Premium-Hoje/marketplace`, build do frontend), renderizado em 28/10/2026. São a evidência de origem deste sistema, não material de marca: não use em peças, só em comparação e revisão.

- `legado-logo-whatsapp.png`: foto de perfil do grupo/canal GPH no WhatsApp, anterior ao protótipo web (640px). É o único registro do logo completo: símbolo (lojinha com toldo, silhueta `#FAD3E8`) + wordmark ("GPH" `#ED2590`, condensado, bold, inclinado) sobre fundo vinho `#17030E`. Fonte do token `simbolo` e da seção "O letreiro" do Brand System.
- `legado-home-desktop.jpg`: página inicial a 800px. Navbar com "GPH" magenta, links lilás, botão rosa; pergunta em ciano, dois selects roxos, botão Pesquisar; abas de categoria; rodapé magenta.
- `legado-home-celular.jpg`: a mesma página a 375px, com o menu recolhido e as abas em duas linhas.
