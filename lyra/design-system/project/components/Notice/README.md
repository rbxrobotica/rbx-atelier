# Notice

Aviso em linha com ícone, texto e ações opcionais. Quatro tons: estimativa (`warn`), informação (`vega`), sincronizado (`ok`) e falha (`err`).

- O consumidor fornece: o tom, a primeira frase em negrito com o fato, a causa e a próxima ação quando for erro.
- O aviso de estimativa usa o texto obrigatório do README. Falha de hash diz o ID, o hash esperado e que nada foi exibido.
