# ReadingBlocks

A leitura em três blocos, ordem fixa: 1 de 3 O que mudou, 2 de 3 Quanto custa para o seu perfil, 3 de 3 O que observar. Títulos em `title-2`, itens numerados em `body`, valores em `data`, fonte de cada item como selo mono.

- O consumidor fornece: os itens de cada bloco, a tabela de impacto e a frase de total.
- O bloco 2 leva o selo Estimativa, a frase de contexto da rota de referência e a tabela. Sem perfil declarado, o bloco 2 mostra o bloqueio ou o convite a configurar o perfil, nunca um valor.
- Não reordene, não renomeie e não omita blocos.
