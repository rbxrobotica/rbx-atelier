# AssumptionsPanel

Painel de premissas da edição, coluna direita de 320 px: aviso de estimativa primeiro, depois perfil declarado, dados do dia e fontes, em pares chave e valor com valores em `data`.

- O consumidor fornece: o perfil declarado, as referências usadas no cálculo, o horário do cálculo e as fontes.
- O aviso de estimativa é obrigatório e vem antes de qualquer número.
- Abre pelo botão Premissas do cabeçalho e fecha pelo botão Fechar.
