# PlanLock

Bloqueio por plano no fluxo: cadeado, título, uma frase que diz o que o plano atual inclui e duas ações: Conhecer o Pro (primário) e Abrir a leitura semanal (silencioso).

- O consumidor fornece: o plano atual e a data da última leitura disponível nele.
- Aparece abaixo do envelope bloqueado, com carimbo de hora. A manchete genérica continua visível; o conteúdo não.
