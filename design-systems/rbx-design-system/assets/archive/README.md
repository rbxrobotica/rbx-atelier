# Archived assets

`rbx-mark.svg` and `rbx-wordmark.svg` are the brand pieces this design system was first built with: the letters RBX over a brass bar, and "RBX Systems" with the same bar. The house is now Merovelis Systems, and its mark is a drawn shape with no letters. The current files are `../merovelis-mark.svg` and `../merovelis-wordmark-systems.svg`, copies of the ones in `brand-voltage/`; the rules are in `brand-voltage/BRAND-MARK.md`.

Kept as a record. Do not use them in new work.
