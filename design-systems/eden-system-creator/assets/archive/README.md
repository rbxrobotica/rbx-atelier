# Archived assets

The six files here are the brand pieces this design system was first built with, all from before the house had its current mark and name:

| File | What it is |
|---|---|
| `rbx-mark.svg` | The disc with diagonal cuts, the mark of the house until 2026-11-08 |
| `rbx-mark-geometric.svg` | A geometric R monogram, an alternative from the same study |
| `rbx-wordmark.svg`, `rbx-wordmark-systems.svg` | "RBX" and "RBX Systems" in the earlier drawing |
| `rbx-wordmark-robson.svg`, `rbx-wordmark-truthmetal.svg` | Product lockups with the house. Robson and TruthMetal are internal names and have no lockup with the house now |

The house is now Merovelis Systems. The current files are `../merovelis-mark.svg`, `../merovelis-mark-on-light.svg`, `../merovelis-wordmark-systems.svg` and `../merovelis-wordmark-systems-stacked.svg`, copies of the ones in `brand-voltage/`; the rules are in `brand-voltage/BRAND-MARK.md`.

Kept as a record. Do not use them in new work.
