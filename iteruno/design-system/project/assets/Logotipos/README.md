# Logotipos

Assinaturas da Iteruno Tecnologias (Brand System de 31/10/2026, direção Sinal). O símbolo é o satélite com arcos de sinal, reconstruído do avatar de 2021; a wordmark é Saira Condensed convertida em contorno. Nunca escreva "Iteruno" em texto vivo no lugar do logotipo: use os arquivos ou o componente `Logo`.

| Arquivo | Uso | Tintas |
| --- | --- | --- |
| `iteruno-horizontal.svg` | Assinatura padrão em fundos claros (cabeçalho, documentos, assinatura de e-mail). Proporção 5,09 : 1 | símbolo `marca`, texto `texto` |
| `iteruno-horizontal-escuro.svg` | A mesma, para fundos escuros | `marca` e `texto` do tema escuro |
| `iteruno-horizontal-curto.svg` | Sem TECNOLOGIAS, para alturas abaixo de 40 px (barra de navegação, rodapé) | como a padrão |
| `iteruno-horizontal-mono-tinta.svg` / `-mono-branco.svg` | Uma tinta: carimbo, gravação, sobre foto | #16231F / #FFFFFF |
| `iteruno-vertical.svg` / `-escuro.svg` / `-mono-branco.svg` | Espaços quadrados ou altos: capa, cartaz, etiqueta. Proporção 1,09 : 1 | como as horizontais |
| `iteruno-wordmark.svg` / `-escuro.svg` / `-curto.svg` | Só o nome, quando o símbolo já está perto (hero, capa de apostila) | texto |
| `iteruno-simbolo.svg` / `-escuro.svg` / `-branco.svg` / `-tinta.svg` | Símbolo isolado: ícone, selo, marcador de seção | #008066 / #35C4A0 / #FFFFFF / #16231F |
| `iteruno-avatar.svg` | Avatar redondo (reprodução do de 2021): Instagram, WhatsApp, Google | fundo #008066, traço branco |
| `iteruno-favicon.svg` | Versão simplificada para 16 a 32 px | fundo #008066, traço branco |
| `iteruno-app-icon.svg` | Ícone de app e PWA, 512 px, sem cantos (a plataforma recorta) | fundo #008066, símbolo branco |

**Cor:** fundo claro, símbolo em `marca` e texto em `texto`; fundo escuro, as versões `-escuro`; fundo em `marca`, só a mono branca (nunca verde sobre verde).

**Área de proteção:** x = metade da altura das capitulares de ITERUNO, livre em volta de qualquer assinatura.

**Tamanhos mínimos (tela):** horizontal 220 px de largura; curta 110 px; vertical 120 px; símbolo 24 px de altura; abaixo disso, só o favicon.

**Proibido:** esticar, girar ou inclinar; separar os arcos do satélite; recolorir ou aplicar gradiente; sombra, contorno ou brilho; alterar a proporção símbolo/wordmark; alinhar outro logotipo ao lado do símbolo.
